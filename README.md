1. SoulCare – AI Mental Health Companion

SoulCare is an AI-powered chatbot designed to provide emotional support, track user well-being, and generate meaningful insights from conversations.

Live Demo: https://soulcare-bot.vercel.app/chatbot  
GitHub Repository: https://github.com/dishasharma23-prog/soulcare-bot  


2. Features of the chatbot include:

- Conversational AI Chatbot
  - Provides empathetic and supportive responses  
  - Designed for mental well-being and daily check-ins  

- Weekly Report Generation
  - Analyzes user interactions over time  
  - Generates summaries of emotional patterns  

- Insights Dashboard
  - Helps users understand mood trends  
  - Encourages self-reflection through data  

- Real-Time Chat Interface
  - Smooth and responsive UI  
  - Instant interaction with the chatbot  

3. Tech Stack

- Frontend: Next.js, React  
- Backend: Node.js (API routes)  
- Deployment: Vercel  
- Architecture: Full-stack web application with real-time interaction  



4. How It Works

1. User interacts with the chatbot through a clean chat interface  
2. The system processes input and generates context-aware responses  
3. Conversations are analyzed to detect emotional patterns  
4. Weekly reports and insights are generated for user reflection  



5. Inspiration

This project was inspired by the need for accessible emotional support in everyday life.  

As a student living away from home, there are moments when having someone to talk to can make a real difference. SoulCare was built to explore how AI can provide a sense of comfort, reflection, and support during such times.
